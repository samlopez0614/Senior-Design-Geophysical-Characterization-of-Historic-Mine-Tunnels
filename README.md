# Senior Design - Geophysical Characterization of Historic Mine Tunnels

### **Members**: Molly Bilhartz, Samantha Lopez, Tessa Murphy

**Historic Onyx Mines | Steamboat Springs, CO | Fall 2026**

**Description**:
Non-invasive geophysical techniques can be used to identify and characterize subsurface structures such as mine tunnes, which pose potential public safety hazards if left undocumented. This study uses Electro-Magnetics, Electrical Resistivity Tomography (ERT), and Gravity measurments to identify and characterize mine tunnels below Howelsen Hill, in Steamboat Springs, CO. The team completed various surveys atop Howelsen Hill to gather the data driving this project.

**Methods**:
- Electro-Magnetics: GEM-2
- Electrical Resistivity Tomography (ERT): ABEM Terrameter
- Gravimetry: CG-5

This Git Hub repository includes any relevant data, Jupyter notebooks, figures, resources, and reports that we used or created throughout the course of this project.
